# Generated Documentation Artifacts

This folder is reserved for generated documentation outputs.

## Policy

- Place machine-generated reports, exports, and snapshots here.
- Do not treat files in this folder as authored source-of-truth docs.
- If a generated artifact becomes a maintained document, move it to:
  - `docs/reports/` for reviewer-facing reports, or
  - another explicit authored location under `docs/`.

## Naming Convention

Use timestamped or build-tagged names, for example:

- `ui_metrics_2026-02-27.json`
- `coverage_summary_ci-1234.md`
